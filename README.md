# HR Management System - Gold Serv

Система управления сотрудниками для компании с поддержкой отслеживания статистики по складам, управлением директорами и HR функциями.

## Возможности

- **HR Панель**: управление сотрудниками, статистика по складам, история присваиваний
- **Страница Директора**: просмотр сотрудников по складам, фильтрация по владельцам
- **Управление Владельцами**: создание и управление владельцами/директорами
- **Историческое Отслеживание**: полная история изменений присваиваний сотрудников и статистики
- **Ролевой Доступ**: поддержка ролей администратора, HR, директора, простого пользователя

## Требования

- Python 3.8+
- SQLite (по умолчанию) или другая база данных
- FastAPI
- SQLAlchemy

## Установка

1. Установите зависимости:

```bash
pip install -r req.txt
```

2. Настройте переменные окружения в `.env`:

```
DATABASE_URL=sqlite:///app.db
HOST=0.0.0.0
```

3. Примените миграции:

```bash
alembic upgrade head
```

4. Запустите сервер:

```bash
python main.py
```

Сервер будет доступен на `http://localhost:8000`

## Основные API Эндпоинты

### Директора

- `GET /directors/list` - список директоров
- `GET /directors/{id}/stats` - статистика по складу
- `POST /directors/me/stats` - обновить статистику текущего пользователя

### Локации

- `GET /locations/list` - список локаций
- `GET /locations/{id}` - детали локации
- `POST /locations` - создать локацию

### Сотрудники

- `GET /employees/list` - список сотрудников
- `POST /employees/assign` - присвоить сотрудника владельцу
- `GET /employees/history` - история присваиваний

### Владельцы

- `GET /owners/list` - список владельцев
- `POST /owners` - создать владельца

## Базы Данных

### Основные Таблицы

- `users` - пользователи системы
- `locations` - склады/локации
- `location_days` - запись склада на день
- `location_day_stats` - статистика склада на день
- `location_day_owners` - владельцы назначенные на день
- `employees` - сотрудники
- `employee_days` - присваивание сотрудника на день
- `warehouse_directors` - директора складов
- `owners` - владельцы/управляющие

### Таблицы История

- `employee_days` - история присваиваний сотрудников (с отслеживанием изменений)
- `warehouse_directors_history` - история директоров

## Ключевые Особенности

### Копирование Статистики

При инициализации нового дня система автоматически копирует:

- Статистику со склада (последнее значение с предыдущего дня)
- Владельцев, назначенных на предыдущий день
- Присваивания сотрудников

### Отслеживание История

- Все изменения присваиваний сотрудников логируются
- История директоров ведется отдельно
- Поддержка просмотра данных на любую историческую дату

### Управление Правами

- Администратор: полный доступ
- HR: управление сотрудниками и статистикой
- Директор: просмотр своего склада и сотрудников
- Пользователь: ограниченный доступ

## Развёртывание

### Для Разработки

```bash
python main.py  # На localhost:8000 с автоперезагрузкой
```

### Для Production

1. Используйте production сервер (gunicorn, uvicorn в режиме production):

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4
```

2. Используйте переменные окружения для конфигурации
3. Установите HTTPS с помощью reverse proxy (nginx, Apache)
4. Используйте production базу данных (PostgreSQL вместо SQLite)
